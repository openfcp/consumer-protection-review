# 保险类产品审查要点与违规模式库

> 适用范围：寿险、健康险、意外险、重疾险、年金险、车险、万能险、投连险、分红险、团体险等。
> 核心依据：《保险销售行为管理办法》（金融监管总局令2023年第2号）、《银行保险机构消费者权益保护管理办法》（9号令）、《互联网保险业务监管办法》、《保险法》第17条、《广告法》。

---

## 一、按产品类型定位审查重点

| 产品类型 | 审查重点 | 高频违规点 | 优先核查条款 |
|----------|----------|-----------|-------------|
| **百万医疗/健康险** | 免赔额、续保条件（保证续保 vs 审核续保）、既往症、等待期、赔付比例、医院范围 | "0免赔"不说明适用范围；"保证续保"实为一年期产品；片面对比竞品赔付比例 | 销售办法17(3)、26；9号令22 |
| **重疾险** | 疾病定义、赔付条件（确诊/达到状态/实施手术）、等待期、轻中症比例、分组与多次赔付限制 | "确诊即赔"但条款要求特定状态或治疗手段；堆砌疾病数量却不说明分组 | 销售办法17(3)；9号令23 |
| **定期寿/终身寿** | 保险责任、免责（自杀、故意犯罪、战争）、等待期、现金价值 | 把寿险说成"储蓄""传承理财"；隐瞒前期现金价值极低 | 销售办法17(2)(3)、25 |
| **年金/增额终身寿** | 领取年龄与方式、现金价值增长逻辑、分红/万能不确定性、退保损失 | "复利3.0%写进合同"混淆保额增长与收益率；用演示利益当承诺；隐瞒前五年退保巨亏 | 销售办法22；9号令22、23 |
| **意外险** | 保障期间、职业类别限制、意外定义、免赔额、除外责任（高风险运动、酒后） | "1元投保"首月低价次年高价；隐瞒职业限制；把猝死当意外赔 | 销售办法17(3)、19；9号令22 |
| **车险** | 险种组合、免赔率、无赔款优待、免责（无证/酒驾/改装）、理赔流程 | "返现""送油卡"等合同外利益；隐瞒出险后次年保费上浮 | 销售办法17(3)；9号令28 |
| **万能险/投连险** | 初始费用、风险管理费、账户管理费、部分领取手续费、最低保证利率、投资账户风险 | 只演示高档结算利率；"保底3%"未说明仅为最低保证利率；把投连险比作基金 | 销售办法22；9号令22、23；广告法25 |
| **分红险** | 红利不确定性、红利实现率、演示假设 | 把高档演示当"预期收益"；不披露历史红利实现率 | 销售办法22；人身险信息披露办法 |
| **团体/雇主责任险** | 被保险人范围、与工伤保险衔接、理赔主体 | 宣传为"员工福利保险"，实为雇主责任险，赔款归企业 | 9号令21、22 |

## 二、通用审查清单

### A. 必须具备的信息（缺失即问题）

- [ ] 明示**所宣传的是保险产品**（不得表述为存款、理财、储蓄、基金）
- [ ] 产品名称（与审批/备案名称一致）
- [ ] 保险期间 / 缴费期间 / 缴费方式
- [ ] 保障范围与保险金额（含赔付比例、分项限额）
- [ ] **责任免除条款**提示（不能只写"详见条款"）
- [ ] **免赔额 / 免赔率 / 比例赔付**说明
- [ ] **等待期 / 观察期**说明
- [ ] **续保条件**（保证续保 or 需审核；是否因理赔或健康变化拒保）
- [ ] **犹豫期**及退保规则、退保损失（长期险必查）
- [ ] **现金价值**说明（长期险）
- [ ] 费率或费率获取方式
- [ ] 投保人**如实告知义务**提示
- [ ] 投诉与咨询渠道（客服电话、报案途径）
- [ ] "具体保障范围以保险合同为准"或等效声明
- [ ] 分红/万能/投连的**利益不确定性**提示

### B. 必须排除的表述（出现即问题）

- [ ] 绝对化用语：顶尖、最优、第一、唯一、100%、零风险、必赔
- [ ] 确定性收益承诺：保本保息、稳赚不赔、复利X%写进合同
- [ ] 日/月保费拆分且未同显著度展示年缴总保费
- [ ] 竞品对比但对象不明确、数据不可验证
- [ ] 只讲优势、回避限制条件
- [ ] 利用焦虑、恐惧、亲情、攀比施压
- [ ] 无真实依据的"限时""停售""抢购"
- [ ] 把不确定的收益/保障说成确定
- [ ] 标注服务"市场价"却不说明使用条件
- [ ] 用监管审批/备案作为安全性背书
- [ ] 合同约定外的利益承诺（返现、送礼、垫付保费）

### C. 显著性与可理解性（最容易漏）

- [ ] 免责与风险提示的**字号**是否明显小于正文（小于正文 70% 视为不显著）
- [ ] 是否位于**折叠区、页脚、需多次点击**才能看到的位置
- [ ] 收益数字与风险提示的**视觉权重**是否失衡
- [ ] 专业术语（免赔额、现金价值、犹豫期、等待期、比例赔付）是否用通俗语言解释
- [ ] 视频/直播中的风险提示是否**画面内出现且停留足够时长**，而非片尾一闪

## 三、高频违规模式库

### 3.1 价格误导类

| 模式 | 典型表述 | 审查要点 | 依据 |
|------|----------|----------|------|
| 日/月保费拆分 | "≈1元/天""首月0元""每月仅需X元" | 是否以同等显著方式展示年缴/总保费；续期保费是否大幅上涨未提示 | 销售办法17(3)；9号令22 |
| 隐形费用 | 宣传低保费，不提初始费用、风险管理费、账户管理费 | 是否完整披露全部费用项目 | 9号令22 |
| 价格锚定 | "原价XX，现价XX"无真实原价依据 | 原价是否真实成交过；是否虚构原价 | 广告法28；价格法14 |
| 首月低价诱导 | "1元投保""0元领取" | 首月后费率是否陡增；是否在显著位置说明首月与续期差异 | 互联网保险办法；9号令23 |

### 3.2 保障范围误导类

| 模式 | 典型表述 | 审查要点 | 依据 |
|------|----------|----------|------|
| 夸大保障 | "全面保障""无缝衔接""全覆盖" | 实际保障范围是否与表述一致；重大风险是否未覆盖 | 销售办法17(3) |
| 模糊免责 | 只讲保障责任，完全不提免责 | 免责是否以显著方式提示、是否解释 | 销售办法26 |
| 确诊即赔 | "确诊即赔""一站式理赔" | 实际赔付条件是否远复杂于宣传（需特定状态/手术/等待期） | 9号令23 |
| 0免赔误导 | "0免赔"未说明适用范围 | 是否仅适用部分责任；其他责任免赔额 | 销售办法17(3) |
| 保额虚高 | "最高600万" | 是否标注"最高"及触发条件、分项限额、赔付比例 | 9号令21、22 |

### 3.3 收益误导类

| 模式 | 典型表述 | 审查要点 | 依据 |
|------|----------|----------|------|
| 确定性收益承诺 | "保本保息""稳赚不赔""复利3.5%" | 收益是否确定；分红/万能账户是否不确定 | 销售办法22 |
| 演示利益当承诺 | 用高档演示表说"每年领X万" | 是否标注低/中/高三档；是否提示红利不保证 | 销售办法22；信息披露办法 |
| 隐瞒投资风险 | 只展示账户价值增长曲线 | 是否提示账户价值波动、最低保证利率含义 | 9号令22、23 |
| 混淆保险与理财 | "理财产品""存款替代""类存款" | 是否明示保险产品性质 | 销售办法17(2) |
| 保额增长冒充收益率 | "3.0%复利递增"实为保额递增 | 是否说明是保额增长率而非投资收益率 | 9号令23 |

### 3.4 营销手段违规类

| 模式 | 典型表述 | 审查要点 | 依据 |
|------|----------|----------|------|
| 炒停售 | "今夜停售""最后3小时""4.025%绝版" | **机构是否已按第十九条公告停售/调价**；未公告即违法 | **销售办法19** |
| 情感操纵 | "孩子的健康防线容不得一丝缺口""不买就亏了" | 是否利用焦虑恐惧亲情影响理性决策 | 9号令23 |
| 虚假案例 | "张女士投保后获赔50万" | 案例是否真实；虚构是否标注"仅为示例" | 广告法28 |
| 不当评比 | "全网销量第一""最受欢迎" | 是否有权威第三方数据、评比标准 | 销售办法17(4) |
| 捆绑销售 | "买A送B""存款送保障" | 是否强制搭售；赠品条件是否如实披露 | 销售办法23；9号令26 |
| 合同外利益 | "返现""送油卡""垫付首期保费" | 是否给予合同约定外利益 | 保险法131 |
| 个人号违规发布 | 代理人朋友圈、短视频号发布 | 是否经**事前审核授权** | **销售办法18** |
| 冒用监管背书 | "银保监备案""国家批准" | 不得利用审核备案程序作引人误解表述 | **销售办法17(5)** |

### 3.5 对比误导类

| 模式 | 典型表现 | 审查要点 | 依据 |
|------|----------|----------|------|
| 片面对比 | 只对比自己优势维度 | 维度是否全面；是否呈现自身劣势 | 销售办法17(3) |
| 模糊对比对象 | "优于市场主流""对比大部分同类" | 对比对象是否明确可识别 | 销售办法17(3) |
| 不当排序 | 自评表格把自己排第一并标"最优" | 排序是否有客观标准；是否暗示官方认证 | 销售办法17(4) |
| 诋毁同业 | "某公司根本赔不了""小公司会跑路" | 是否捏造散布虚假事实 | 销售办法17(4)；反不正当竞争法11 |

### 3.6 渠道与流程违规类

| 模式 | 典型表现 | 审查要点 | 依据 |
|------|----------|----------|------|
| 第三方冒名 | 合作平台以保险公司名义在自营页面销售 | 是否允许第三方以机构名义在网点/自营平台推介 | **9号令25** |
| 默认勾选 | 投保页默认勾选附加险、自动续保 | 是否系统或网页默认勾选 | **销售办法23** |
| 未经同意开收费服务 | 领取权益须先开通收费服务 | 是否单方开通 | 9号令26(2) |
| 主体不明示 | 网络销售页面未显示机构可识别名称 | 是否提示机构名称；非面对面是否说明姓名、机构全称、执业证编号 | 销售办法24 |
| 费率越权 | 宣传费率与备案费率不一致 | 是否按审批/备案条款费率销售 | 销售办法30 |

## 四、按材料形式的补充检查点

| 材料形式 | 特有检查点 |
|----------|-----------|
| **海报/单页** | 主视觉字号分配；风险提示是否被裁切；二维码指向页面是否与海报一致；"广告"标识 |
| **公众号推文/软文** | 标题是否夸大（标题党）；"广告"标识；文末免责是否折叠；跳转链路 |
| **H5/落地页** | 首屏是否披露关键信息；关闭按钮可用性；默认勾选；授权弹窗是否默认同意；自动续费提示 |
| **短视频/直播** | 口播是否与画面字幕一致；风险提示是否口播+字幕双呈现；主播资质；切片二次传播是否失控 |
| **短信/外呼** | 是否含退订方式（"回T退订"）；是否在消费者拒收后重复发送（9号令40）；外呼是否说明身份与录音 |
| **电销/双录话术** | 是否完整提示免责与犹豫期；是否引导消费者回答"是"；是否代客确认（销售办法29） |
| **产品说明会PPT** | 演示利益是否三档；是否使用自制对比表；讲师是否暗示"保本" |

## 五、审查时的三个易错点

1. **只审文案不审条款** — 文案合规但条款本身有问题（如续保条件苛刻），业务部门会说"宣传没写错"。此时应把问题定位到"宣传未披露该限制"，仍是宣传问题。
2. **把"详见条款"当合规** — 关键限制不能只靠一句"详见条款"豁免，必须实质提示。这是最常见的中风险漏判。
3. **忽略二次传播** — 短视频切片、代理人员工转发、截图搬运，都可能脱离原始审核语境。审查应覆盖"可预见的传播形态"。
