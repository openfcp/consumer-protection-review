# 非保险金融产品审查要点与违规模式库

> 适用范围：银行理财、公募基金、信托、信贷、消费金融/分期、互联网贷款与助贷、支付、存款与结构性存款、数字金融产品。
> 核心依据：《关于进一步规范金融营销宣传行为的通知》（银发〔2019〕316号）、《银行保险机构消费者权益保护管理办法》（9号令）、《资管新规》、《广告法》、《消费者权益保护法》、《个人信息保护法》，以及分业监管规章。

---

## 一、按产品类型定位审查重点

| 产品类型 | 审查重点 | 高频违规点 | 优先核查条款 |
|----------|----------|-----------|-------------|
| **银行理财** | 风险等级、收益不确定性、净值波动、业绩比较基准含义、赎回条件、销售起点 | "保本保息""稳赚不赔"；把业绩比较基准说成预期收益；混淆存款与理财 | 9号令22、23；理财办法 |
| **公募基金** | 过往业绩展示规范、费率结构、投资风险、适当性 | 只展示最佳区间收益；"冠军基金"不当评比；隐瞒管理费申赎费；未提示"过往业绩不代表未来" | 9号令22、23；基金销售办法 |
| **结构性存款** | 是否真结构性、收益区间、触发条件、保本性质 | 把结构性存款说成"高息存款"；不说明收益挂钩条件；虚假宣传"保本高收益" | 9号令22、23 |
| **信贷/个人贷款** | 年化利率（APR）、总还款额、逾期费用、提前还款规则、担保费 | 只讲日利率/月费率；"零利率"但收高额服务费；隐瞒提前还款违约金 | **9号令22（明示年化利率）**、28 |
| **消费金融/分期** | 总还款金额、实际年化、违约金、催收方式 | "免息分期"实收手续费；隐瞒逾期罚息；诱导过度借贷 | 9号令22、28、41 |
| **互联网贷款/助贷** | 合作机构管理、营销宣传归属、综合融资成本、催收外包 | 平台以银行名义宣传；综合成本拆分隐藏；导流页面误导 | 9号令14、25；互联网贷款办法；金规〔2025〕9号 |
| **信托** | 投资门槛、风险等级、底层资产、兑付风险、推介合规 | "刚兑"暗示；隐瞒底层资产；夸大历史兑付记录；公开宣传私募产品 | 资管新规；9号令22、23、31 |
| **支付/钱包类** | 收费项目、免密支付、自动扣款、账户安全 | 默认开通免密支付；"免费"后收费；诱导开通信用付 | 9号令24、26；非银支付条例 |
| **存款/大额存单** | 利率、提前支取规则、是否存款保险 | 把理财说成存款；"存款送礼品"变相高息揽储 | 9号令21、22、24 |

## 二、通用审查清单

### A. 必须具备的信息

- [ ] 产品**性质明示**（存款 / 理财 / 基金 / 信托 / 贷款 / 保险，不得混淆）
- [ ] **风险等级**（R1–R5 或机构口径）及风险提示
- [ ] **收益性质**：确定 / 浮动 / 业绩比较基准 / 历史业绩，并说明"不构成收益承诺"
- [ ] **年化利率（APR）**（贷款类必须明示，不得只给日利率或月费率）
- [ ] **费用结构完整**：管理费、托管费、销售服务费、申购赎回费、担保费、服务费
- [ ] **期限与流动性**：产品期限、开放频率、锁定期、赎回到账时间
- [ ] **退出机制**：赎回条件、提前还款规则、违约金
- [ ] **适当性要求**：起购金额、风险承受能力等级、投资经验、年龄限制
- [ ] "**过往业绩不代表未来收益**"（收益型产品必须）
- [ ] **投诉与救济渠道**
- [ ] 发行/管理主体名称与资质

### B. 必须排除的表述

- [ ] 保本、保息、保收益、稳赚不赔、零风险、刚兑、政府兜底
- [ ] 预期收益率、承诺收益率（资管产品禁用）
- [ ] 只给日利率/月费率而隐藏年化
- [ ] 只展示最佳区间/最佳年份业绩
- [ ] 用"国资背景""银行股东""国家支持"暗示安全性
- [ ] "限时""额度有限""马上抢"等无依据紧迫感
- [ ] "免息""0利息"但收取高额手续费
- [ ] 把私募产品向不特定公众宣传
- [ ] 引用未经核实的"权威评级""获奖"作为安全性证明

### C. 显著性、可理解性与适当性

- [ ] 风险提示与收益数字的**视觉权重**是否失衡
- [ ] 业绩比较基准是否说明**测算依据与不构成承诺**
- [ ] 是否用通俗语言解释净值、波动、回撤、年化、复利
- [ ] 是否按消费者风险承受能力匹配产品（不得向低风险客户推高风险产品）
- [ ] 老年客户是否有额外保护措施（冷静期、二次确认、人工提示）

## 三、高频违规模式库

### 3.1 收益误导类

| 模式 | 典型表述 | 审查要点 | 依据 |
|------|----------|----------|------|
| 确定性收益承诺 | "年化8%""保本保息""稳赚不赔" | 收益是否确定；是否提示不保证 | 广告法25；资管新规；9号令23 |
| 业绩比较基准误导 | "预期收益4.5%""年化4.5%" | 是否使用"业绩比较基准"规范表述；是否说明不构成承诺 | 理财办法；9号令22 |
| 选择性业绩展示 | 只展示近3个月/最佳年份 | 是否展示完整区间（成立以来、近1/3/5年）；是否含亏损期 | 基金销售办法；9号令23 |
| 收益率算法误导 | 单利当复利、年化算法不披露 | 计算方式、假设条件是否标注 | 广告法28 |
| 历史业绩暗示未来 | "过去5年年年正收益" | 是否同时提示"过往业绩不代表未来" | 9号令22 |
| 保额/规模冒充收益 | "累计为客户赚了X亿" | 与个体收益无关，是否暗示个人可得 | 9号令23 |

### 3.2 费用与利率误导类

| 模式 | 典型表述 | 审查要点 | 依据 |
|------|----------|----------|------|
| 隐瞒真实利率 | "日息万分之五""月费率0.6%" | 是否明示**年化利率**；是否折算展示 | **9号令22** |
| 零利率陷阱 | "0利息""免息分期"收高额手续费 | 综合年化成本是否完整披露 | 9号令23、28 |
| 砍头息 | 放款时预扣利息/服务费 | 是否从本金预扣；实际到账与合同本金是否一致 | **9号令28(3)** |
| 变相收费 | 以咨询费、担保费、会员费名义额外收费 | 是否在约定收费外变相收费 | **9号令28(4)** |
| 费用隐藏 | 只展示前端费用，隐藏管理费/赎回费 | 是否完整披露所有费用项目 | 资管新规；9号令22 |
| 会员捆绑 | 不买会员无法正常还款/查询 | 是否强制搭售 | 9号令26 |

### 3.3 风险隐瞒类

| 模式 | 典型表现 | 审查要点 | 依据 |
|------|----------|----------|------|
| 刚兑暗示 | "历史100%兑付""从未亏损" | 是否暗示保本保收益 | 资管新规；9号令23 |
| 政府/银行背书暗示 | "国资背景""银行存管=安全" | 是否暗示信用背书；实际风险是否提示 | 9号令23；银发316号 |
| 风险等级美化 | 高风险产品标"稳健型" | 风险等级是否与产品实质匹配 | 9号令20、22 |
| 适当性错配 | 向老年客户推 R4/R5 产品 | 是否评估并匹配风险承受能力 | 9号令11；适当性办法 |
| 底层资产不透明 | 只说"优质资产""分散投资" | 是否披露底层资产类别与集中度 | 9号令22 |

### 3.4 营销手段违规类

| 模式 | 典型表述 | 审查要点 | 依据 |
|------|----------|----------|------|
| 饥饿营销 | "额度仅剩XX万""今日截止" | 是否有真实额度/期限依据 | 银发316号；9号令23 |
| 情感/焦虑操纵 | "钱放银行就是贬值""不理财就落后" | 是否利用焦虑施压 | 9号令23 |
| 虚假案例 | "客户投入10万变30万" | 是否真实；虚构是否标注示例 | 广告法28 |
| 不当评比 | "收益率排名第一""最受欢迎" | 是否有权威第三方数据与统计口径 | 银发316号 |
| 以教育之名营销 | "理财课堂"直接推产品 | 是否以营销替代知识普及 | 9号令35 |
| 骚扰式触达 | 短信/电话/推送无退订 | 是否提供拒收退订；退订后是否停止 | **9号令40** |
| 诱导过度借贷 | "先享后付""额度随便用" | 是否诱导超出还款能力的借贷 | 9号令23；消金办法 |

### 3.5 竞争与对比违规类

| 模式 | 典型表现 | 审查要点 | 依据 |
|------|----------|----------|------|
| 片面对比 | 只对比收益率不比风险 | 维度是否全面、同口径 | 银发316号 |
| 贬低同业 | "某平台跑路""别家都是坑" | 是否捏造散布虚假信息 | 反不正当竞争法11 |
| 蹭监管/权威 | "央行认证""国家试点" | 是否利用公信力背书 | 银发316号 |
| 榜单自制 | 自制排行榜自评第一 | 榜单来源与标准是否可验证 | 银发316号；广告法28 |

### 3.6 渠道与信息违规类

| 模式 | 典型表现 | 审查要点 | 依据 |
|------|----------|----------|------|
| 第三方冒名 | 助贷平台以银行名义宣传贷款 | 是否允许第三方以机构名义推介 | **9号令25** |
| 默认勾选授权 | 隐私政策默认同意、捆绑授权 | 线上格式条款授权**不得设默认同意** | **9号令44** |
| 超范围收集 | 贷款必须授权通讯录、位置 | 是否最小必要；是否变相强制 | 9号令43、47；个保法6 |
| 跨平台传数据 | 与合作方共享客户名单营销 | 未经同意不得跨平台传递 | 9号令46 |
| 私募公募化 | 私募信托/基金公开宣传、朋友圈推介 | 是否向不特定对象宣传；是否变相降低门槛 | 资管新规；9号令31 |
| 汇聚资金 | 组织多人凑钱买私募 | 是否组织诱导归集资金 | **9号令31** |

## 四、按材料形式的补充检查点

| 材料形式 | 特有检查点 |
|----------|-----------|
| **APP 首页/弹窗** | 弹窗是否可一键关闭；"领额度""测额度"是否实为贷款申请；默认勾选 |
| **贷款申请页** | 年化利率是否在首屏显著展示；是否展示总还款额；保险/会员是否默认勾选 |
| **收益展示页** | 业绩比较基准的字体大小是否小于收益率数字；是否含完整区间 |
| **直播/短视频** | 主播是否具备资质；是否口播风险提示；"关注领福利"是否导流销售 |
| **短信/外呼** | 退订方式；是否冒充官方；是否在拒收后重复发送 |
| **合作渠道页面** | 是否明示实际金融机构；是否存在"XX银行旗下"误导；导流链路是否留存 |

## 五、审查时的四个易错点

1. **把"业绩比较基准"当合规挡箭牌** — 若字体远小于收益率、位置在折叠区、又配"稳健增值"文案，实质仍构成误导，不能因用了规范术语就放行。
2. **只看年化利率数字不看总成本** — 年化利率合规但叠加担保费、会员费后综合成本畸高，应作为公平交易权问题提出。
3. **忽略"合作机构"环节** — 助贷、导流、代销场景下，宣传由谁发出、以谁名义发出，决定责任归属，必须问清。
4. **把私募当公募审** — 私募类产品的第一问题不是文案，而是"是否向不特定公众宣传"，这一条不成立，其余都不用谈。
