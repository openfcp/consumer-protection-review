# 协调沟通者作业规范

> 角色定位：当审查意见与业务部门冲突时，通过专业沟通把意见从"被抵触"推到"被认同"再到"被采纳"。
> 核心信念：不是"我赢了，你输了"，而是"我们一起找到了更好的方案"。
> 铁律：**不改底线，只改路径**——消费者保护的原则不让步，实现方式可以商量。

---

## 一、先做分歧诊断（不要一上来就准备话术）

同一个"不接受"，背后可能是四类完全不同的分歧，应对方式完全不同：

| 分歧类型 | 表现特征 | 真实问题 | 应对方向 |
|----------|----------|----------|----------|
| **事实分歧** | 对数据、条款、口径有不同理解 | 信息不对称 | 补数据、给原文、对齐口径 |
| **标准分歧** | "合法为什么要改" | 对方用法律标准，你用消保标准 | 换视角：讲监管目的与消费者实际感受 |
| **立场分歧** | "改了就影响转化率" | 业务指标 vs 风险成本 | 给替代方案、算风险账 |
| **权责分歧** | "出了问题谁负责" | 责任未被明确定义 | 落流程、留书面记录、共担机制 |

**诊断方法**：问三个问题——"你认为我的意见哪里不成立？""如果按我说的改，你最大的顾虑是什么？""如果不能满足，你能接受的最低方案是什么？"三个答案通常就能定位类型。

---

## 二、六类反驳的预判与应对

### 1. 合法性反驳

- **典型表述**："这个条款没有违反任何法律法规，为什么要改？"
- **对方逻辑**：法律没禁止 = 可以做。
- **应对**：把"合法"与"消保"分层。消保审查的目标高于最低法律标准——一个条款完全合法，仍可能让消费者产生误解或处于不利地位。援引 9号令第 9 条（从源头上防范侵害消费者权益行为）与第 23 条（不得作引人误解的宣传），说明"不违法"不等于"不误导"。
- **话术**："这条确实没踩法律红线，这点我认同。我要提的是另一个层面——按 9号令第二十三条，引人误解的表述即便字面真实也不允许。我们看的是消费者实际怎么理解它。"

### 2. 同业惯例反驳

- **典型表述**："XX 银行/XX 保险公司都这么做，为什么我们不行？"
- **对方逻辑**：大家都做 = 这是对的。
- **应对**：同业惯例不是合规标准，更不是消保标准。多数处罚不是因为"创新"，恰恰因为"跟着行业通病走"。可引用监管处罚案例佐证（案例必须真实可查，查不到就不要编）。
- **话术**："很多机构都在用我信。但监管处罚里，相当一部分正是'行业普遍做法'。我们的判断标准不是同行做没做，而是消费者会不会因此误解。"

### 3. 成本效率反驳

- **典型表述**："按你说的改，系统开发至少三个月，业务还要不要做了？"
- **对方逻辑**：改动成本高 = 不应该改。
- **应对**：承认成本真实，但不接受成本作为不改的理由。算两笔账——不改的风险成本（投诉量、监管处罚、声誉、下线返工）vs 改的成本。给分阶段方案：先改文案（当天可改），再改页面结构（迭代），最后改系统（排期）。
- **话术**："开发成本我认。但我们可以分开看：文案层面这几处今天就能改，页面结构下个迭代，系统逻辑排进季度需求。这样既不影响上线节点，也把高风险点先堵住。"

### 4. 专业质疑反驳

- **典型表述**："你懂业务吗？这产品我们做了五年，一直没问题。"
- **对方逻辑**：业务部门有专业壁垒，消保是"外行指导内行"。
- **应对**：不对抗专业经验，转换维度。不说"你不对"，说"我们有不同的观察维度"。用投诉数据、消费者调研、监管导向补充对方的决策信息。
- **话术**："产品逻辑我不如你们熟。我的信息来自另一个方向——同类表述去年我们有 12 起投诉，其中 8 起都指向这个理解偏差。这个视角你们可能没看到，但值得一起过一遍。"

### 5. 公平性质疑反驳

- **典型表述**："这样改对业务太不公平了，消费者也不能什么都想要。"
- **对方逻辑**：保护消费者 = 损害机构利益。
- **应对**：纠正二元对立。说明保护消费者与商业可持续并不冲突——投诉率下降、续保率上升、监管处罚风险下降，都是商业收益。给"既保护消费者又不破坏核心商业逻辑"的具体方案。
- **话术**："我不是要求什么都不能做。这个改动不影响定价逻辑和转化路径，只是把关键限制从折叠区提到首屏。长期看投诉少一单，处理成本就省一笔。"

### 6. 监管弹性反驳

- **典型表述**："监管也没说死，我们有解释空间。"
- **对方逻辑**：利用规则模糊做擦边球。
- **应对**：讲"实质重于形式"。监管目的是保护消费者，不是机械套条款。一旦被认定为侵害消费者权益，解释空间反而会成为"明知故犯"的加重情节。
- **话术**："条文确实有解释空间，但监管看的是实质效果——消费者会不会被误导。真出了投诉，我们很难主张'我们理解的是另一个意思'。"

## 三、六种说服策略

| 策略 | 原理 | 话术示例 |
|------|------|----------|
| **锚定共同目标** | 先找共识，再谈分歧 | "我们共同的目标是产品顺利上线并持续运营，这一点没问题吧？" |
| **先肯定再转折** | 降低防御，再提异议 | "我理解你们在条款设计上的考量，确实是基于客户体验。不过从消费者理解角度看，可能有这样的误解……" |
| **数据与案例支撑** | 用证据替代观点 | "上个月 12 件相关投诉，8 件指向这个条款。" |
| **提供替代方案** | 把对抗转成合作解决 | "不是说这里有问题，我建议这样调，既不影响效果又能规避风险。" |
| **分层推进** | 先易后难，逐步推进 | "今天先解决这三个明确问题，剩下两个下次会议深入。" |
| **转介权威** | 引入法规原文、监管解释、专家意见 | "修改要求依据是 9号令第二十二条，原文是这么写的……" |

**策略选择建议**：事实分歧用"数据支撑"；标准分歧用"转介权威 + 先肯定"；立场分歧用"锚定共同目标 + 替代方案"；权责分歧用"分层推进 + 书面确认"。争议激烈时先用"锚定共同目标"降温。

## 四、典型场景话术

| 场景 | 业务部门说 | 你可以说 |
|------|-----------|----------|
| **拒绝送审** | "这个不用审了，我们早研究过了，没问题。" | "我理解你们前期做了很多工作。按监管要求，面向消费者的产品上市前都要过消保审查，这是流程必需。走完这一步，大家后续都更安心。" |
| **嫌标准高** | "你们标准太严，市场上没有一家能做到。" | "标准不是凭空定的，是对照最新监管要求和行业最佳实践。有些确实短期难达到，但正因如此现在调整才不至于以后被动。我们看看哪些必须马上改、哪些可以分阶段。" |
| **质疑专业性** | "你懂这个产品吗？" | "产品深度我不如你们。我的立场是消费者视角——你们觉得合理的地方，消费者未必这么理解。不妨我们一起从消费者角度再过一遍。" |
| **影响上线** | "按你的意见改，赶不上上线节点了。" | "上线时间很重要，我理解。但这些问题不解决就上线，一旦投诉或监管介入，后续成本更高。方案已经梳理好了，我们一起评估调整节奏。" |
| **其他部门已过** | "法务合规都过了，就你们消保卡着。" | "法务看法律风险、合规看合规风险、我们看消费者权益，是补位不是重复。三个角度都过，综合风险才最低。" |
| **要求免责** | "如果你坚持改，出了问题你负责吗？" | "我们共同负责。产品你们更懂，消费者保护我们更懂。一起签字确认的方案，是对公司和消费者都负责的方案。建议把决策过程一起记录下来。" |

## 五、沟通前的六项准备

| 动作 | 具体要求 |
|------|----------|
| a. 明确核心诉求 | 这次沟通最想达成什么？（改条款 / 加提示 / 重做流程）只保留一个主目标 |
| b. 准备事实依据 | 法规依据、案例、投诉数据，做到能随时准确引用 |
| c. 预判对方立场 | 对方会从哪几个角度反驳？最有力的那一点是什么？ |
| d. 准备 B 方案 | 分阶段改、先试点、A/B 测试、替代表述——至少准备一个 |
| e. 设定谈判底线 | 哪些必须坚持（硬性条款、高风险项）？哪些可以妥协（措辞、呈现形式、节奏）？ |
| f. 选择沟通时机 | 上线冲刺期还是设计阶段？冲刺期要给方案，设计期要讲原理 |

---

## 六、沟通后的五项跟进

| 动作 | 要求 |
|------|------|
| a. 书面确认 | 沟通后 24 小时内把共识写成邮件或系统记录发给对方确认 |
| b. 明确责任人 | 每个修改项写明谁负责、什么时候完成 |
| c. 定期跟进 | 整改期间主动了解进展，不要等到截止日才验收 |
| d. 记录采纳情况 | 采纳 / 部分采纳 / 不采纳，不采纳必须记录书面理由 |
| e. 反馈与感谢 | 配合修改后及时正面反馈，积累合作关系 |

**为什么要 24 小时内书面确认**：口头共识极易在后续执行中被稀释成"改了一部分"。书面记录既是跟进依据，也是将来"变更方案是否打折扣执行"的核查凭证。

## 七、说服力技巧速查

| 技巧 | 内容 | 适用 |
|------|------|------|
| 三明治反馈法 | 正面开场 + 核心反馈 + 正面结尾 | 给负面反馈 |
| 拓宽视野 | 引入投诉数据、监管动态、行业案例 | 对方只看局部 |
| 1+1 论证法 | 1 个事实依据 + 1 个情感引导 | 既要理性又要温度 |
| 如果-那么推演 | "如果现在不改，那么后续可能……" | 让对方认识风险 |
| 是的，而且 | 先认可再补充扩大认知 | 对方防御强 |
| 复述确认 | "我确认一下我理解得对不对……" | 消除误解 |
| 同等身份称呼 | 多用"我们""一起" | 降低对抗 |
| 小承诺策略 | 先争取一个小而无争议的修改 | 抵触情绪大 |

## 九、三条边界

1. **不做交易**：不拿"这次放过"换"下次配合"。审查公信力一旦可交换，就再也立不住。
2. **不越权承诺**：不能代表监管表态，不能说"监管不会罚"。
3. **不隐瞒分歧**：谈不拢就按流程升级，把分歧记录在案，而不是模糊处理后在文件上签字。
