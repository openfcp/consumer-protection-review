## 二、核心法规：审查中最常援引的八部

### 1. 《银行保险机构消费者权益保护管理办法》（银保监会令 2022 年第 9 号）

- 公布 2022-12-26，**施行 2023-03-01**，共 8 章 57 条。业内简称"9号令"。
- **地位**：银行保险业消保领域层级最高、内容最全面的基础性规章，是消保审查机制的法定来源。`已核原文`

**必记条款索引**：

| 条款 | 内容要点 | 审查用途 |
|------|----------|----------|
| **第九条** | 应建立**消保审查机制**，对面向消费者的产品和服务在**设计开发、定价管理、协议制定、营销宣传**环节审查；新产品或条款重大变化时应审查 | **一切审查工作的法源**；也是"应审尽审"的依据 |
| 第十条 | 信息披露机制，遵循真实性、准确性、完整性、及时性，售前售中售后全流程披露关键信息 | 披露机制类问题 |
| 第十一条 | 适当性管理机制，产品风险分级、消费者风险测评 | 风险错配 |
| 第十二条 | 销售行为可回溯管理 | 双录、页面留痕 |
| 第十三条 | 个人信息保护机制，全流程分级分类管控 | 信息类问题 |
| 第十四条 | 合作机构名单管理，协议须约定信息安全、价格、信息披露、纠纷解决等 | 合作渠道责任 |
| 第十五条 | 投诉处理工作机制，畅通渠道、规范流程、溯源整改 | 投诉渠道告知缺失 |
| 第十六条 | 纠纷多元化解；消费者申请调解，机构**无正当理由不得拒绝** | 救济渠道告知 |
| 第二十条 | 优化产品设计，准确评定产品风险等级 | 产品设计类 |
| **第二十一条** | 保障知情权，使用**通俗易懂**的语言和有利于消费者接收理解的方式披露；对**专业术语解释说明**；及时真实准确揭示风险 | 术语堆砌、看不懂的文案 |
| **第二十二条** | 应以**显著方式**披露产品和服务的**性质、利息、收益、费用、费率、主要风险、违约责任、免责条款**等可能影响消费者重大决策的关键信息；**贷款类产品应明示年化利率** | 披露完整性与显著性的核心条款 |
| **第二十三条** | 不得进行**欺诈、隐瞒或者误导性宣传**；不得作**夸大产品收益或服务权益、掩饰产品风险**等虚假或引人误解的宣传 | 表述准确性、收益误导 |
| 第二十四条 | 服务价格公示，新设收费项目或提价应**提前公示** | 收费类 |
| 第二十五条 | 不得允许第三方合作机构在网点或自营网络平台**以机构名义**推介销售 | 渠道越界 |
| **第二十六条** | 自主选择权五项禁止：强制捆绑/搭售；未经同意单方开通收费服务；利用业务便利强制指定第三方收费服务；不正当手段诱使购买其他产品；其他 | 搭售、默认勾选 |
| 第二十七条 | 风险收益匹配、定价合理、计量正确；同等交易条件不得**不公平定价** | 差别定价 |
| **第二十八条** | 公平交易权六项禁止：格式合同不合理加重消费者责任/限制排除合法权利；减轻免除机构义务或责任；**从贷款本金预扣利息**；约定收费外以咨询费佣金名义**变相额外收费**；限制寻求法律救济；其他 | 格式条款审查主条款 |
| 第二十九条–第三十二条 | 财产安全权；身份识别；公私募严格区分；核保理赔规则标准**版本管理**，不得事后改用不同标准 | 理赔类 |
| 第三十三条 | 不得**拖延理赔、无理拒赔** | 理赔承诺类 |
| 第三十四条–第三十五条 | 受教育权；金融知识教育宣传应坚持**公益性，不得以营销、推介行为替代**知识普及 | "以教育之名做营销" |
| 第三十六条–第三十九条 | 受尊重权；不得歧视性差别对待；适老化、无障碍 | 弱势群体保护 |
| **第四十条** | 电话、短信、网络推送营销须提供**拒收或退订**选择；拒收后**不得以同样方式再次发送** | 骚扰式营销 |
| 第四十一条 | 催收规范；禁止冒用行政司法机关名义、暴力恐吓欺诈 | 催收话术 |
| **第四十二条–第四十八条** | 信息安全权；告知目的方式范围并取得同意；不得变相强制、违规购买；**线上格式条款授权不得设置默认同意选项**；合作方管控；最小必要授权 | 信息授权类 |
| 第五十条 | 涉消保重大事件应及时向监管报告 | 重大风险提示 |
| 第五十三条 | 监管措施：监管谈话、责令限期整改、风险提示函、责令内部问责、责令暂停部分业务、通报或公布 | 说明后果严重性时引用（勿夸大） |
| 第五十四条 | 处罚：通报批评、警告、10 万元以下罚款；严重侵害情形可对董事高管警告并处 10 万元以下罚款 | 说明后果 |

### 2. 《保险销售行为管理办法》（金融监管总局令 2023 年第 2 号）

- 公布 2023-09，**施行 2024-03-01**。`已核原文`

**⚠️ 高频引用错误提醒**：不少内部材料把"禁止虚假夸大宣传"写成"第十五条"，实际第十五条是**保险产品分级管理制度**。宣传行为的正确条款是**第十七条**。请勿沿用错误引用。

| 条款 | 内容要点 | 审查用途 |
|------|----------|----------|
| 第七条 | 个人信息合法正当必要诚信，合作协议须明确合作方信息处理要求 | 信息类 |
| 第十三条 | 条款制定应要素完整、结构清晰、文字准确、表述严谨、通俗易懂；专业术语符合国标/行标 | 条款可读性 |
| 第十四条 | 官网/APP 公示产品条款与产品说明；产品说明应突出**审批备案名称、保障范围、保险期间、免除或减轻保险人责任条款、保单预期利益**；停用条款须公告并标注起始日期 | 产品说明审查 |
| 第十五条 | 建立**保险产品分级管理**制度（复杂度、保费负担、保单利益风险） | 产品分级（不是宣传条款） |
| 第十六条 | 销售人员销售能力分级，差别授权 | 销售资格 |
| **第十七条** | **保险销售宣传六项要求**：①形式与实质不超出业务许可范围与区域；②**明示所宣传的是保险产品**；③不得引用不真实不准确的数据资料，**不得隐瞒限制条件**，不得虚假或夸大表述，不得使用**偷换概念、不当类比、隐去假设**等不当手段；④不得捏造散布虚假事实恶意诋毁竞争对手，不得**不当评比、不当排序**，不得冒用近似商标字号；⑤**不得利用监管审核或备案程序**作引人误解表述；⑥不得违反其他规定 | **保险营销宣传审查的核心条款** |
| **第十八条** | 销售人员**未经授权不得发布**宣传信息；机构负管理主体责任，应**事前审核及授权发布**，发现自行编发须制止处置 | 自媒体/个人号宣传 |
| **第十九条** | 停售或调价应在官网显著位置和营业场所公告；**公告前销售人员的不得宣称产品即将停售或调价** | **饥饿营销的硬性依据** |
| 第二十一条 | 应了解投保人保险需求、风险特征、缴费能力、已购同类保险，确定可购买的类型与等级范围 | 适当性 |
| **第二十二条** | 销售**人身保险新型产品**应提示**保单利益的不确定性**并准确全面提示风险；需风险承受能力测评的应测评并按结果销售 | 分红/万能/投连收益误导 |
| 第二十三条 | 禁止强制搭售；禁止利用**信息系统或网页默认勾选**订立合同；强制搭售的界定（含购买非保险金融产品时未告知即要求同时投保） | 默认勾选、搭售 |
| 第二十四条 | 网络销售须提示机构可识别名称；非面对面销售须说明销售人员姓名、机构全称、**执业证件编号** | 主体资质明示 |
| **第二十五条** | 投保前应提供**格式条款及产品说明**，并明确提示五类内容：①订立的是**保险合同**；②合同基本内容（产品名称、主要条款、保障范围、保险期间、保险费及交费方式、赔偿限额、**免除或减轻保险人责任的条款**、索赔程序、退保及其他费用扣除、现金价值、**犹豫期、宽限期、等待期**、效力中止与恢复）；③违反如实告知义务的后果；④机构服务电话及咨询报案投诉途径；⑤其他 | 投保提示完整性清单 |
| **第二十六条** | 对**免除或减轻保险人责任的条款**，应以足以引起注意的文字、字体、符号或其他明显标志**提示**，并对其概念、内容及法律后果作**明确解释说明**；范围包括**责任免除条款、免赔额、免赔率、比例赔付或给付** | 免责提示显著性审查主条款 |
| 第二十七条 | 提示如实告知义务；询问不得用无具体内容的概括性条款 | 健康告知话术 |
| 第二十八条 | 需求明显不符、缴费能力明显不足、重复/超额保险时应建议终止投保，并说明风险、确认自愿 | 劝退义务 |
| 第三十条 | 严格按经审批或备案的条款费率销售 | 私改费率 |
| 第三十一条 | 按销售方式采取录音录像、页面管理、操作轨迹记录等**可回溯**管理 | 留痕 |

### 3. 《关于进一步规范金融营销宣传行为的通知》（银发〔2019〕316 号）

- 人民银行、原银保监会、证监会、外汇局联合发布，2019-12 发布，**2020-01-25 施行**。`待核验（条款序号）`
- **地位**：跨行业金融营销宣传的通用规范，覆盖银行、保险、证券、支付、基金等全领域，是**非保险类宣传审查的第一依据**。

核心要求（按行为归类，条款序号引用前须复核）：

- **资质**：未取得金融业务资质的市场主体**不得**开展相关金融营销宣传；不得超出业务许可范围。
- **内容真实性**：不得虚假、欺诈、隐瞒或引人误解；不得引用不真实、不准确的数据和资料；不得**对过往业绩或收益作保证性承诺**；不得夸大产品收益或服务能力、掩饰产品风险。
- **不得利用公信力**：不得利用政府、监管机构、行业协会的名义或形象作背书；不得使用"国家批准""监管备案"等暗示安全性。
- **不得损害公平竞争**：不得贬低、诋毁同业。
- **风险提示**：应显著提示产品或服务的风险；应说明"过往业绩不代表未来表现"（收益型产品）。
- **投诉渠道**：应提供投诉、咨询的渠道和方式。
- **互联网渠道**：不得以欺骗方式诱导点击；不得影响他人正常使用网络；弹窗须可一键关闭。
- **合作方**：委托第三方营销的，应明确责任，不得任由第三方以自身名义发布未经审核内容。

### 4. 《中华人民共和国消费者权益保护法》

| 条款 | 要点 | 用途 |
|------|------|------|
| 第八条 | 消费者享有知悉商品或服务**真实情况**的权利 | 知情权兜底 |
| 第二十条 | 经营者不得作**虚假或者引人误解**的宣传；提供信息应真实全面 | 误导表述兜底 |
| 第二十六条 | 格式条款不得作出排除或限制消费者权利、减轻或免除经营者责任、加重消费者责任等**不公平不合理**规定；不得以格式条款等方式强制交易 | 格式条款兜底 |

### 5. 《中华人民共和国广告法》

| 条款 | 要点 | 用途 |
|------|------|------|
| 第九条 | 禁用"国家级""最高级""最佳"等**绝对化用语** | 绝对化表述 |
| 第二十五条 | 招商等有**投资回报预期**的商品或服务广告，应对可能存在的**风险及风险责任承担作合理提示或警示** | 投连险、理财、基金广告 |
| 第二十八条 | **虚假广告**认定（商品/服务不存在、信息与实际情况不符且影响购买、虚构使用效果等） | 虚假宣传定性 |

### 6. 《中华人民共和国保险法》

| 条款 | 要点 | 用途 |
|------|------|------|
| 第十七条 | 采用格式条款的，应提供投保单并附格式条款、说明合同内容；对**免除保险人责任的条款**，应作出足以引起注意的提示并明确说明；**未明确说明的，该条款不产生效力** | 免责条款效力（注意：这是法律后果，审查中描述事实，不做定性） |
| 第一百三十一条 | 保险代理人、经纪人及其从业人员禁止欺骗投保人、隐瞒与合同有关的重要情况、给予合同约定外利益 | 销售行为 |

### 7. 《中华人民共和国个人信息保护法》

| 条款 | 要点 | 用途 |
|------|------|------|
| 第十三条、第十四条 | 处理个人信息应取得**同意**，同意应自愿、明确；法律行政法规规定应单独同意的从其规定 | 授权合法性 |
| 第十七条 | 处理前应以显著方式、清晰易懂语言真实准确完整告知处理者身份、目的、方式、种类、保存期限 | 告知充分性 |
| 第二十四条 | 自动化决策应保证透明度和结果公平公正，不得对个人在交易条件上实行不合理差别待遇 | 精准营销、差别定价 |
| 第二十九条 | 处理**敏感个人信息**应取得**单独同意** | 健康告知、生物识别 |

### 8. 《中华人民共和国反不正当竞争法》

- 第八条：不得作虚假或引人误解的**商业宣传**（对商品性能、功能、质量、销售状况、用户评价、曾获荣誉等）。
- 第十一条：不得编造、传播**虚假或误导性信息**损害竞争对手商业信誉、商品声誉。
- `待核验`：该法已于 2025 年修订，**条文序号可能调整**，引用前须核对现行文本。

## 八、检索策略

**法规检索**
- 关键词结构：`法规全称 + 条款号 + 关键词`，来源限定 `site:nfra.gov.cn` / `site:gov.cn`。
- 官方入口：国家金融监督管理总局（nfra.gov.cn）"法规"栏目；中国政府网（gov.cn）"国务院公报"；中国人民银行（pbc.gov.cn）；国家市场监督管理总局（samr.gov.cn）；中国人大网（npc.gov.cn）查法律原文。

**处罚案例检索**
- 关键词：`机构名称 + 行政处罚 + 虚假宣传 / 误导销售 / 欺骗投保人`。
- 优先来源：金融监管总局及派出机构行政处罚公示、原银保监会/银保监局罚单、"行政执法信息"栏目。
- 引用要求：机构名称、处罚决定书文号、时间、违规事实、处罚结果五要素齐全；**缺任何一项不得作为案例引用**。

**交叉验证**
- 核心条款至少两个权威来源一致；仅有一个来源时标注 `[单一来源，建议复核]`。
- 微信公号、律所解读可作为线索，**不得**单独作为条款依据。

**效率规则**
- 单次审查涉及 ≥3 个独立子主题（不同法规 / 不同产品 / 不同案例集）且互不重叠时，可并行检索；同一主题不得拆分并行，避免重复与口径不一。
