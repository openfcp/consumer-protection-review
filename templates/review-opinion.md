# 审查意见单模板

> 适用：R1 风险识别者的标准交付物，L1/L2 深度均可用。
> 命名：`审查意见_{产品名称}_{YYYYMMDD}.md`

---

```markdown
# 消保审查意见单

**审查编号**：CP-REV-{年份}-{流水号}
**审查日期**：YYYY-MM-DD
**审查人**：{姓名}
**审查深度**：L1 快速扫描 / L2 逐项审查 / L3 深度审查

---

## 二、审查意见清单

| 序号 | 问题描述 | 原文引用（含位置） | 风险等级 | 涉及权益 | 法规依据 | 整改建议 | 时限 |
|------|----------|-------------------|----------|----------|----------|----------|------|
| 1 | | "...原文..." （主视觉区第2行） | 高 | 知情权 | 《银行保险机构消费者权益保护管理办法》第22条 | | 立即 |
| 2 | | | 中 | 自主选择权 | | | 5个工作日 |
| 3 | | | 低 | | | | 下个版本 |

**填写要求**
- 原文引用须精确到句，标注位置（第几屏/第几段/主视觉区/页脚）。
- 风险等级：高 = 明确违反强制性规定或可能造成资金损失/群体投诉/处罚；中 = 未直接违反条款但违背监管目的；低 = 表述不规范可优化。
- 涉及权益按八项权益填写，一条可多选。
- 整改建议必须写"改哪句、改成什么"，并给出替代方案（如删除不可行）。
- 时限：立即 / 3 个工作日 / 5 个工作日 / 下个版本迭代。

## 三、审查结论

**结论：通过 / 有条件通过 / 不通过**

| 结论 | 含义 | 后续动作 |
|------|------|----------|
| 通过 | 无高风险问题，中风险 ≤2 项且可即时修订 | 归档，中风险纳入迭代跟踪 |
| 有条件通过 | 无未解决高风险问题，存在需限期整改的中风险 | 生成整改任务单，整改完成前不得投放，整改后复查归档 |
| 不通过 | 存在 ≥1 项高风险且无法局部消除，或存在系统性误导 | 退回重做；重大分歧升级至消保委员会 |
```

## 附：L1 快速扫描的精简版

```markdown

**材料**：{名称}　**产品类型**：{}　**扫描日期**：{}

| # | 命中问题 | 原文 | 等级 | 依据 |
|---|----------|------|------|------|
| 1 | | | 高 | |

**初步判断**：存在 N 项高风险，建议进入 L2 逐项审查 / 未见明显硬伤。
**未覆盖维度**：D4 对比公平性、D5 营销手段全项（L1 不展开）。
**说明**：本意见为快速扫描，不构成完整审查结论。
```
